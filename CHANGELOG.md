# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-11-10

### Добавлено
- Вкладка **«Журнал»**: живой вывод сборки и загрузки прямо в TUI (интерфейс больше не закрывается), строка прогресса,
  кнопка «Остановить» (SIGINT → SIGTERM → SIGKILL всей группе процессов), история `backup.log`.
- Загрузка в Telegram из TUI: кнопки «Собрать», «Загрузить в Telegram», «Собрать и загрузить»; состояние архивов по
  директориям (собрано, размер, загружено N/M); подтверждения перед загрузкой «секретных» папок без шифрования и перед удалением томов.
- `tg_upload.py check` — пошаговая диагностика (сеть, сессия, аккаунт, группа); `topics --json`, `groups --json`; общий `--timeout`.
- `.state/tui.log` — журнал TUI с трейсбеками неожиданных сбоев.
- Переменные окружения `BACKUPUTIL_NONINTERACTIVE`, `BACKUPUTIL_PV_FORCE`.

### Изменено
- Telegram в TUI работает через тот же `tg_upload.py` дочерним процессом (как в CLI), а не внутри процесса интерфейса.
- Вход в аккаунт из TUI выполняется в настоящем терминале (код и пароль 2FA вводятся там).
- Сообщения `tg_upload.py` (логи, шаги) идут в stderr, stdout — только данные и JSON.
- Быстрый отказ для `check`/`topics`/`groups`: таймаут установки соединения 25 с вместо многоминутного ожидания.

### Исправлено
- В TUI соединение с Telegram «не устанавливалось» без каких-либо сообщений: запросы выполнялись без таймаута, пустые ошибки
  (`TimeoutError`) показывались как «Ошибка: », а любой сбой нестандартного типа мог молча завершить интерфейс.
- Вкладка «Журнал» не открывалась автоматически из-за возврата фокуса на нажатую кнопку.
- Остановка процесса зависала, если потомок удерживал вывод после завершения основного процесса.

## [1.0.0] — 2026-11-08

### Добавлено
- Терминальный интерфейс (`./backup.sh tui`): источники с деревом каталогов, сопоставление топиков, вход в Telegram,
  параметры, редактор исключений, запуск с предпросмотром команды.
- Режим «каждый элемент директории — отдельный архив» (по умолчанию) и `--whole` для одного архива на директорию.
- Сопоставление топиков по названию без учёта регистра; запасной путь получения топиков для старых версий Telethon.
- Метки `autoback#N` (полный бэкап) и даты (частичный), продолжение прерванного полного бэкапа, `--fresh`.
- Секционный файл исключений: `[*]` и `[имя_директории]`.
- `restore.sh --only`, проверка только выбранных томов.
- Автотесты (pytest, Textual Pilot, сквозной `smoke.sh`), CI, документация.

### Изменено
- Один файл `<имя>.sha256` и один `MANIFEST.txt` на директорию (в манифесте — перечень архивов).
- Личные конфиги отделены от шаблонов (`*.example`, `excludes.default.txt`); `.gitignore` — белый список.

### Исправлено
- Запрос списка топиков использовал неверное пространство имён Telethon (`channels` вместо `messages`).

## [0.1.0]
